# Ajedrez Anime

Juego web para 2 jugadores en el mismo dispositivo, según el «Reglamento de habilidades».

## Cómo jugar
- Abrí `index.html` en Chrome (doble clic), o el link de Claude.
- Cada bando elige en secreto: su Noble (Princesa, Príncipe o Renegado), dónde esconde al Joker y al Peón Oscuro,
  y **3 de las 6 habilidades de cada pieza** (el Rey tiene 7 para elegir). Todas las piezas del mismo tipo comparten esas 3.
- Entre turnos aparece una pantalla de pase para que el rival no vea el Joker, las trampas ni la Transmigración.
- La partida se guarda sola en el navegador («Continuar la partida guardada»).

## Decisiones donde el reglamento no dice nada
- Las **reacciones** saltan solas cuando hay Ki (cada una se puede apagar en el panel de la pieza).
- Si una reacción cancela un ataque, el atacante recupera el Ki y tiene que hacer otra jugada.
- Si una habilidad toca al rey camuflado o a un Joker que vale más de lo que parece, **rebota**: se revela la pieza y el atacante hace otra jugada.
- Las habilidades que «capturan» mueven a la pieza a la casilla capturada, salvo el Cañón.
- Coronación normal: caballo, alfil, torre o tu Noble. Con Coronación Oscura: cualquier Noble.
- Sombra Doble y Trile dejan elegir si el cambio es real o fingido.
