# Skills elegidas para tu Claude

(Word, PDF, Excel, PowerPoint, pósters, creador de skills, artifacts y los paquetes de diseño, marketing y datos).

| Skill | Qué te suma | De quién | Revisión |
|---|---|---|---|
| `frontend-design` | Páginas y apps con diseño cuidado, no genérico (sitios web, la tienda del juego, etc.) | Anthropic (oficial, Apache 2.0) | Solo texto |
| `webapp-testing` | Claude abre tu página en un navegador, hace clics, saca capturas y te dice qué falla | Anthropic (oficial, Apache 2.0) | Un script que solo prende servidores en tu compu (localhost) |

## Ya instaladas en Claude Code
Están en `.claude/skills/` de este repo: cualquier sesión de Claude Code en este proyecto las usa sola.

## Para la app o la web de Claude
1. Descargá el `.zip` de esta carpeta (abrilo en GitHub → botón de descarga).
2. En Claude: **Configuración → Capacidades → Skills → Subir skill** y elegí el `.zip`.

## Adobe for Creativity (no es un archivo, es un conector)
Para retocar fotos, plantillas de Express y variantes para redes:
**Configuración → Conectores → buscar «Adobe» → Conectar**. Según Adobe funciona mejor en la app de escritorio de Claude.
